# Java JDBC CRUD Application

A simple and practical CRUD (Create, Read, Update, Delete) application developed using **Core Java, JDBC, and MySQL**.

## Features
- Create new records in the database
- Retrieve and display records
- Update existing records
- Delete records
- Connect Java applications with MySQL using JDBC
- Use PreparedStatement for executing SQL queries

## Technologies Used
- Java
- JDBC
- MySQL
- SQL
- Maven (if applicable)

## Learning Objectives
- Understand JDBC architecture and database connectivity
- Perform CRUD operations using Java
- Work with SQL queries and PreparedStatement
- Manage database interactions in Java applications

## How to Run
1. Clone the repository.
2. Configure your MySQL database.
3. Update the database connection credentials.
4. Run the Java application.

This project is built for learning and practicing Java database connectivity and backend development fundamentals.
